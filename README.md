## What I've built

### TapIn HR
An employee time and attendance platform for UK small businesses.
Built from scratch and deployed to production using AWS and AI-assisted development tools.

**Live at:** https://www.tapinhr.co.uk

Staff clock in and out on a tablet kiosk. Managers get automated payroll reports, absence tracking with Bradford Factor, holiday pay calculations and real-time wage costs — all in one place.

Built on AWS serverless infrastructure (Lambda, DynamoDB, Cognito, CloudFront, API Gateway) with a React frontend. Multi-tenant, GDPR compliant, live with real customers.
